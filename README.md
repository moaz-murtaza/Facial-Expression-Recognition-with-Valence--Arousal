# CS452 – Deep Learning Assignment 1

This repository contains the implementation and results for **Assignment 1: Facial Expression Recognition and Continuous Emotion Prediction**. Two baseline models were evaluated: **ResNet18** (11.18M parameters) and **MobileNetV2** (2.23M parameters). Both were trained for 10 epochs using ImageNet-pretrained weights, batch size 64, and Adam optimizer with cosine learning rate scheduling. The task included categorical emotion recognition (7 classes) and continuous valence–arousal regression. Training logs, confusion matrices, scatter plots, and qualitative prediction samples are included alongside the LaTeX report.

Results show that **ResNet18 outperforms MobileNetV2** in classification accuracy (38.9\% vs 34.6\%) and macro F1 (0.379 vs 0.325), while also achieving more stable regression performance. MobileNetV2, while lightweight and computationally efficient, tends to collapse predictions toward neutral values. The report discusses the rationale for evaluation metrics (Accuracy, F1, RMSE, CORR, SAGR, CCC) and highlights CCC as the most suitable metric for in-the-wild emotion systems. All figures and results are integrated into the provided LaTeX report.
